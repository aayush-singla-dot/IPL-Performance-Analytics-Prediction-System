# IPL Performance Analytics & Prediction System

## Overview
End-to-end Machine Learning system to predict IPL match outcomes using advanced feature engineering and explainable AI.

## Features
- Match winner prediction
- Advanced features (win rate, head-to-head, recent form)
- Explainable predictions (SHAP - upcoming)
- Streamlit web app (upcoming)

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn, XGBoost
- SHAP
- Streamlit

- src/
- models/
